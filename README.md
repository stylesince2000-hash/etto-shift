# 食・酒・楽 笑っと（ETTO） シフトアプリ

居酒屋「食・酒・楽 笑っと」のスマホ用シフト管理アプリ。**単一ファイル `index.html`**（素のHTML/CSS/JS）に全機能を内包。データ同期は Firebase Realtime Database、ホスティングは **GitHub Pages 自動デプロイ**。

- 本番URL: https://stylesince2000-hash.github.io/etto-shift/
- リポジトリ（Public）: https://github.com/stylesince2000-hash/etto-shift

> この README は公開リポジトリに入るため、パスワード等の秘密は書きません。詳細な運用メモは、各自のPCローカルにある `CLAUDE.md`（gitignore・非公開）を参照してください。

## 他PCで続きを始める手順
```bash
gh auth login          # 初回のみ：GitHubにログイン
git clone https://github.com/stylesince2000-hash/etto-shift
cd etto-shift
claude                 # このフォルダで Claude Code を起動し、まず CLAUDE.md を読ませる
```
- **作業前**に必ず `git pull`、**作業後**は下記手順で `git push`。
- シフトの入力データは Firebase 上にあるので、どのPCで編集しても本番データは共通。

## 主な機能

### ⏰ タイムカード
厨房に貼ったQRをスマホのカメラで読むと、パスワード無しで打刻画面が開きます（`?tc=1`）。
- 名前をタップすると、**その人が今できる操作だけ**が大きなボタンで出ます（未出勤→出勤 / 勤務中→休憩・退勤 / 休憩中→戻る）
- 深夜営業に対応。営業日は朝5時に切り替わるので「20時出勤→翌2時退勤」が1日分として集計されます
- 押し間違えたら「⚠️ 打刻を間違えた」から店長に報告 →店長が時刻を直せます
- 店長は ⏰勤怠タブで 当日の状況 / 修正依頼 / 給与集計（実働・深夜・支給額）を確認できます
- 時給・深夜時給・締め日・深夜時間帯・端数は ⚙️設定 で変更できます
- **入口はQRだけ**。アプリ内に打刻ボタンは置いていません（席に座ったまま打刻するのを防ぐため）
- **場所チェック（任意）**: 打刻時にGPSで位置を確認し、店から離れていたら「⚠️店外 ○m」と赤く記録します。既定では打刻を止めません（屋内でGPSがずれても打てなくならないように）。設定で「店外なら止める」に変更もできます

### 📖 予約
実際の店内配置に合わせたフロア図で予約を管理します。**従業員も編集できます**。
- 座敷 1・2・3・5・6・7（上段）＋ 8（左下）、カウンター 1〜6席（4番の座敷はありません）
- 予約は**席を決めずに登録**し、あとからフロア図の空席をタップして割り当てます
- **ご来店時間はドラム式（30分刻み）**。iPhoneのアラームと同じ操作感で、1目盛りごとに音と触覚が返ります
- 「19:00〜19:30に来店」のような**幅のある予約**にも対応（ちょうど／〜30分／〜1時間）
- 予約カードの「🪑 席を選ぶ」を押すと、フロア図の席をタップするだけで**追加・解除を連打**できます（1・2・3とポンポン押して卓を繋げる／減らす）
- 開くとまず「🗺 席で見る」（1日ぶんのフロア図）。「📋 一覧」に切り替えると **今週・来週・再来週・📅カレンダー** で見られます
- カレンダーは日ごとの予約組数が出ます。日付をタップするとその日の席へ
- 電話番号はタップでそのまま発信できます
- **1席1組**です（回転は扱いません）。埋まっている席には別の予約を入れられません
- 座敷1〜7は**繋げられます**。同じ組を隣の卓にも入れると1つの卓として表示されます
- シフトの日付を開くと、その日の予約組数・人数も表示されます

### 🍽 メニュー
- **レギュラー**と**おすすめ（ホワイトボード）**を切り替えて管理します
- 料理名・**省略名（伝票に書くときの略し方）**・値段・カテゴリを登録します
- 「✏️ 略名をまとめて入力」で、一覧のまま略名を直接打てます（Enterで次の品へ）
- 省略名は将来の「伝票の読み取り」で使うので、実際に伝票に書いている略し方をそのまま入れます
- 料理名でも省略名でも検索できます。まとめて登録（1行1品）にも対応
- 従業員・管理者のどちらからでも編集できます

### 📅 シフト
- **従業員**: 名前を選んで、月カレンダー／週リストで ○希望・△調整可能・×休み ＋ 備考を入力。「確定シフト」タブで自分／みんなの予定を確認。
- **管理者**: 集計、シフト編成（日付をタップして出勤者を選択）、店休日の設定、⚙️設定（スタッフ管理・パスワード変更・伝達事項）。
- **全体**: 伝達事項バナー、日ごとのイベント・予約メモ、全端末リアルタイム同期、ホーム画面追加（PWA）、開きっぱなし端末の自動アップデート。

**定休日は月曜**（自動）。祝日は営業扱い。臨時の店休・例外営業は「🚫 店休」タブで日付をタップして切り替えます。

## 変更のデプロイ
1. `index.html` を編集。
2. 動作に影響する変更なら `index.html` の `APP_VERSION` と `version.json` の `version` を**同じ新しい値**に上げる。
3. `git add -A && git commit -m "..." && git push` → 1〜2分で本番反映。
